# Assessments

Claude's assessments of the project submissions,
made with the [`judge-submissions`](../.claude/skills/judge-submissions/SKILL.md) skill.
Each is scored from 1 to 5 on five criteria;
potential impact and the license check are described but not scored.
The assessments are published so teams can review and compare them.
